# TV Mute

Крошечное приложение для Xiaomi Mi TV (Android 9, MiTV-MSSP1): перехватывает только кнопку Mi
и не влияет на остальные кнопки пульта.

- **Короткое нажатие кнопки Mi** — включить/выключить звук.
- **Удержание кнопки Mi от 0,5 секунды** — штатное действие кнопки: переход в PatchWall.

## Что делает приложение

Приложение устанавливает службу доступности **TV Mute**, которая следит только за одной
клавишей пульта — кнопкой Mi (код 191). Все остальные кнопки (громкость, стрелки, OK, Домой,
Назад и другие) служба сразу пропускает дальше и никак на них не влияет.

Без включённой службы кнопка Mi работает как обычно — открывает PatchWall.

## Как включить службу

На этой прошивке нет экрана «Специальные возможности», поэтому кнопка «Открыть настройки»
в приложении ведёт в общие настройки ТВ — саму службу можно включить только через ADB.

Требования: на телевизоре включён режим разработчика и отладка по сети, компьютер и ТВ
в одной локальной сети.

```
adb connect АДРЕС_ТВ:5555
adb install -r TVMute.apk
adb shell settings put secure enabled_accessibility_services ru.digit.tvmute/ru.digit.tvmute.MuteAccessibilityService
adb shell settings put secure accessibility_enabled 1
```

Затем перезагрузите телевизор и откройте приложение «TV Mute» — там должно быть
«Служба: включена». Служба запускается сама при каждой загрузке.

## Как проверить

- Коротко нажмите Mi — звук выключается, ещё раз — включается.
- Удерживайте Mi от 0,5 секунды — откроется PatchWall, звук при этом не меняется.
- Коротко нажмите OK на плитке приложения на главном экране — приложение должно
  открыться сразу, а не показывать меню «Открыть / Переместить / Удалить».

## Важно знать

- Если выключить службу через ADB, фильтр клавиш может «залипнуть» до перезагрузки.
  Просто перезагрузите ТВ — кнопка Mi вернётся к штатному PatchWall.
- Пока служба включена, удержание кнопок громкости меняет громкость только на один шаг.
  Это ограничение прошивки: любая служба доступности с перехватом клавиш отключает
  автоповтор громкости. Без службы громкость снова «летит» при удержании.

## Требования для сборки

- Windows + PowerShell 5.1+
- Android SDK: `build-tools;35.0.0`, `platforms;android-35`
  (ожидается в `%LOCALAPPDATA%\Android\Sdk`)
- JDK 17 скачивается автоматически в `tools\jdk-17` (около 190 МБ, без установки в систему)

## Сборка

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

Результат: `out\TVMute.apk`. Тесты логики: `build.ps1 -Target test`. Только APK: `build.ps1 -Target apk`.

## E2E-проверка

```
powershell -ExecutionPolicy Bypass -File tests\e2e.ps1
```

## Откат

```
adb shell pm disable-user --user 0 ru.digit.tvmute
adb shell pm enable flar2.homebutton
```

Для полного удаления: `adb uninstall ru.digit.tvmute`.

> Примечание по прошивке: прямое отключение службы или пакета через adb на этом ТВ
> оставляет залипший фильтр клавиш до перезагрузки. Если выключаешь службу, перезагрузи
> телевизор — тогда кнопка Mi вернётся к штатному PatchWall.

## Известные ограничения

- **Удержание кнопок громкости не даёт повтора.** На Android TV `PhoneWindowManager` забирает кнопки
  громкости себе («volume keys never go to the foreground app»), а пульт Xiaomi RC при удержании
  не присылает repeat-события. Это поведение прошивки/пульта, не приложения: ни Button Mapper,
  ни любое другое приложение не может его изменить без root.
